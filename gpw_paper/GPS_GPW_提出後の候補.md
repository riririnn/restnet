### 1.2 SL のモデルの Attention

**言葉の定義**（11-16 に決めた）：共通の量は、1 つのヘッドで、1 つの局面の 1 つの起点のマスから出る重みのうち、最大の重み × 81（均等なら 1）。
- 偏り：ヘッドの数字。81 マスのすべてを起点にして共通の量を求め、起点と局面で平均した値。
- max（重み × 81）：1 枚の図の値。図の起点からの共通の量。
- 集中している：max（重み × 81）が、均等でないといえる線 1.077 を超えること。

**ヘッドの偏り**（floodgate の test の最初の 2,048 局面、data/floodgate/peaked_sl.csv と peaked_sl_rl.csv）

| モデル | 偏りが大きいヘッド（上位 5 つ） | 偏り 3 以上のヘッド | 偏り 1.03 以下のヘッド |
|---|---|---|---|
| SL の 10T（40 ヘッド） | 第 1 T ブロック第 3 ヘッド 22.89、第 7 T ブロック第 3 ヘッド 15.09、第 2 T ブロック第 2 ヘッド 11.22、第 2 T ブロック第 4 ヘッド 10.93、第 4 T ブロック第 1 ヘッド 10.34 | 18 | 15 |
| SL の 10T から始めた RL の 10T（40 ヘッド） | 第 1 T ブロック第 3 ヘッド 23.99、第 7 T ブロック第 3 ヘッド 12.98、第 4 T ブロック第 1 ヘッド 11.53、第 9 T ブロック第 1 ヘッド 10.39、第 2 T ブロック第 2 ヘッド 10.37 | 16 | 18 |
| SL の R3(RRT)（12 ヘッド） | 第 2 T ブロック第 2 ヘッド 10.17、第 1 T ブロック第 3 ヘッド 6.36、第 1 T ブロック第 2 ヘッド 5.94、第 2 T ブロック第 1 ヘッド 4.34、第 3 T ブロック第 2 ヘッド 3.39 | 5 | 4 |
| 論文の自己対局の R3(RRT)（12 ヘッド） | 12 ヘッドとも 1.001〜1.024 | 0 | 12 |

- 同じ構成（R3(RRT)）、同じ局面、同じ測り方で、SL のモデルには偏りの大きいヘッドがあり、論文の自己対局のモデルの重みはほぼ均等。何が違いの原因か（データ、学習の量など）はわからない。
- SL の 10T から始めた RL の 10T でも、SL で偏りの大きかったヘッドは偏りが大きいまま。
- SL から始めた RL の R3(RRT) の偏りは、測っていない。

- **指された手のほうに大きい重みが付く**：指された手と他の手で、指された手のほうに大きい重みが付く割合は、SL の 10T の第 9 T ブロック第 3 ヘッドで 0.803、SL の R3(RRT) の第 2 T ブロック第 2 ヘッドで 0.785（偶然は 0.5、位置のバイアスだけでは最高 0.55〜0.56）。
- **重みを均等にすると policy が変わる**：偏ったヘッドほど、重みを均等にしたときに policy の 1 位が指された手である割合が下がる（SL の 10T の 40 ヘッドで相関 0.80）。
- **集中した重みが手の行き先に向く割合**（11-16）：均等でないといえる線は 1.077（論文の自己対局の R3(RRT) の最大の重み × 81 の最大）。モデルの手（探索なしの policy の 1 位）で動かす駒のマスを起点にしたとき、重みが最大のマスがモデルの手の行き先である割合は、SL の 10T の第 7 T ブロック第 3 ヘッドで 41.0%、SL の R3(RRT) の第 3 T ブロック第 2 ヘッドで 43.1%（floodgate の指された手では 36.0%、36.7%。起点以外の 80 マスから無作為に選ぶと 1.25%）。
- **持ち駒を 1 枚相手に渡したときの重みの変化**（11-16）：floodgate の test の 39,654 局面のうち、モデルの手（policy の 1 位）が駒打ちの局面（SL の 10T 7,416、SL の R3(RRT) 8,305）で、打つ先を起点に、打つ駒を 1 枚相手に渡したときの重み × 81 の変化の最大を、全ヘッドで求めた。
  - 変化が 1 を超える局面の割合が最も大きいヘッドは、SL の 10T の第 7 T ブロック第 3 ヘッド（60.3%、変化の中央値 1.31、最大 23.89）と、SL の R3(RRT) の第 2 T ブロック第 2 ヘッド（53.5%、中央値 1.09、最大 17.72）。どれかのヘッドの変化が 1 を超える局面は 69.1% と 59.6%、5 を超える局面は 7.8% と 3.8%。
  - 同じヘッドの中では、起点からの最大の重み × 81 が大きい局面ほど変化が大きい（変化の最大が 1 を超えるヘッド、SL の 10T の 17 ヘッドと SL の R3(RRT) の 5 ヘッドで、順位相関は +0.11〜+0.54。最も集中した 4 分の 1 の局面の変化の中央値は、最も集中していない 4 分の 1 の 1.30〜6.99 倍と 1.70〜3.76 倍）。
  - 藤井－羽生戦の 118 手目の変化（SL の 10T 5.51、SL の R3(RRT) 3.16）は、それぞれ 94.5% と 89.2% の駒打ちの局面より大きい。論文の自己対局の R3(RRT) は同じ局面で 0.001 以下。
  - 重みそのもの（合計 1）に直すと、9×9 の最大 23.89 は 0.29、論文の動物将棋の図（5.73、重み × 12）は 0.48。どちらも多くの局面の中の最大。
  - 前の局面の持ち駒の平面も変えると、value の下がり方が約 2 倍（平均 −0.169 → −0.332、−0.177 → −0.353）。重みの変化の中央値はあまり変わらない。
  - 図：attention/持ち駒/floodgate_test/（各モデルで変化が最大の 3 局面、重みの差と Attention Map）。出典：data/floodgate/hand_sl.csv、hand_sl.txt、hand_sl_*.npz、scripts/gpw_statistics.sh の step_hand
- **例の図**：attention/SL_10T/ と attention/SL_R3RRT/（各 50 枚）、attention/藤井羽生_118手目/（SL の 10T 40 枚、SL の R3(RRT) 12 枚）。
- **口頭か補足で言うこと**：例の局面の選び方（重みの大きい順）と一致率。例の手は、SL の 10T で 50 のうち 39、SL の R3(RRT) で 50 のうち 47 が駒を取る手。
- **藤井－羽生戦の 118 手目**：探索なしの policy の 1 位は、SL の 10T も SL の R3(RRT) も ▲5六銀打（水匠5 の読みで 13 手の詰み）。1 手 64 シミュレーションの探索をさせると、どちらも実際に指された ▲4七桂打（5 手の詰み）を指す。図の凡例は「SL の 10T の手」とだけ書く（「探索なし」は明白なので書かない。11-16 の本人の決定）。GUI と図の確かめはパネルで行っている（11-16）。

## 2. 新しい結果の候補：動物将棋（論文のモデル）

- **先生の集計の再現**：無作為な 100,000 局面（4 つの向き）で、6T の第 5 T ブロック第 4 ヘッドは、完全解析で良い手のほうに大きい重みを向ける（最善手と他の手 0.774、順位全体 0.701、重みが最大の手が盤上の最も良い手 44.4%、偶然は 19.3%）。乱数の種 1 の表は、すべての値が先生の値と 0.01 以内。
- **ベースライン**：位置のバイアスだけの重みでは 0.518、学習前の重みでは 0.490。0.774 は盤の中身による。
- **学習の途中**：4,000 ステップで 0.488、12,000 で 0.692、40,000 で 0.774。
- **ヘッドの重みを均等にする**：value の符号が完全解析と合う割合が 85.9% から 83.0% に下がる（ほかの 23 ヘッドでは、下がっても 0.07 ポイント）。policy の 1 位が最善手である割合は 0.4 ポイントしか下がらない。
- **モデルの選んだ手と一致する**：policy が最善手を選ばなかった入力では、他の手より大きい重みが付く割合が、policy の手で 0.75、最善手で 0.65。
- **別の学習**：別に学習した 11 構成でも、6T にだけ良い手のほうに大きい重みを向けるヘッドが現れた（第 4 T ブロック第 1 ヘッド、0.85）。ヘッドの場所は学習ごとに違う。
- **R を含む構成**：9 構成の 92 ヘッドは、無作為な局面ですべて重みがほぼ均等（各マスからの最大の重み × 12 の平均が 1.006〜1.019）。
- 出典：gpw_paper/poster_parts.md の まとめと 1〜7 節、mdfolder/attention_map.md の 6b 節

## 3. 限界として伝える候補

- **R を含む自己対局のモデルの query と key**：R を含む構成の query と key の重みは、初期値から weight decay の分しか変わっていない（論文の動物将棋の RRTRRT、論文の 9×9 の R3(RRT) の第 2・第 3 T ブロック）。Attention が使われていない状態。原因はわかっていない。出典：mdfolder/attention_map.md の 6d 節。
- **1 つのヘッド、1 回の学習**：動物将棋の主な結果は、6T の 1 回の学習の 1 つのヘッドの結果で、別の学習では別のヘッドに現れる。
