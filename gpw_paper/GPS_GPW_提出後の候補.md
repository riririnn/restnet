## 1. 新しい結果の候補：9×9 の将棋の SL のモデル

### 1.1 SL の学習と強さ

- floodgate の棋譜（両者のレートが 2250 以上、train 553,309 局）で、10T・R3(RRT)・10R を 150,000 ステップずつ学習した（学習率 0.02、batch 1024）。
- 学習に使っていない test の 39,654 局面で、探索なしの policy の 1 位が指された手である割合は、SL の 10T 0.474、SL の R3(RRT) 0.504、SL の 10R 0.502（論文の R3(RRT) は 0.195）。
- 1 手 1 秒の 100 局で、SL の R3(RRT) は論文の R3(RRT) に 99 勝 1 敗、SL の 10T は論文の R3(RRT) に 100 勝 0 敗、SL の 10R は論文と同じ設定の自己対局の 10R に 99 勝 1 敗。学習の量とデータが違うので、言えるのは「この SL のモデルが強い」まで。
- 水匠5 との対局（11-16、こちらは 1 手 64 シミュレーション、ノイズなし、9 戦型の開始局面で先後を入れ替えて各 90 局）：水匠5 の 1,000 ノードに SL の R3(RRT) 77 勝 13 敗（85.6%）、SL の 10R 78 勝 12 敗（86.7%）。3,000 ノードに 55 勝 35 敗（61.1%）と 61 勝 29 敗（67.8%）。10,000 ノードに 13 勝 77 敗（14.4%）と 13 勝 77 敗（14.4%）。90 局の 95% 区間（Wilson）は 3,000 ノードで 50.8〜70.5% と 57.6〜76.5% で重なり、SL の R3(RRT) と SL の 10R に差があるとは言えない。論文の自己対局のモデルは、10-18 に水匠5 の約 46 ノードでも 0〜8% だった（mdfolder/meeting_2026-10-18.md）。結果は models/9x9_shogi/sl_check/suisho/SL_*_n*.txt。
- 出典：mdfolder/after_gpw_submission.md の 5.5〜5.6 節、models/9x9_shogi/sl_check/

### 1.2 SL のモデルの Attention

- **重みが集中する**：論文の自己対局の R3(RRT) は、12 ヘッドとも重みがほぼ均等（各マスからの最大の重み × 81 の平均が 1.001〜1.024）。SL の R3(RRT) の第 2 T ブロック第 2 ヘッドは 10.2。同じ局面、同じ測り方。何が違いの原因か（データ、学習の量など）はわからない。
- **指された手のほうに大きい重みが付く**：指された手と他の手で、指された手のほうに大きい重みが付く割合は、SL の 10T の第 9 T ブロック第 3 ヘッドで 0.803、SL の R3(RRT) の第 2 T ブロック第 2 ヘッドで 0.785（偶然は 0.5、位置のバイアスだけでは最高 0.55〜0.56）。
- **重みを均等にすると policy が変わる**：偏ったヘッドほど、重みを均等にしたときに policy の 1 位が指された手である割合が下がる（SL の 10T の 40 ヘッドで相関 0.80）。
- **集中した重みが手の行き先に向く割合**（11-16）：均等でないといえる線は 1.077（論文の自己対局の R3(RRT) の最大の重み × 81 の最大）。モデルの手（探索なしの policy の 1 位）で動かす駒のマスを起点にしたとき、重みが最大のマスがモデルの手の行き先である割合は、SL の 10T の第 7 T ブロック第 3 ヘッドで 41.0%、SL の R3(RRT) の第 3 T ブロック第 2 ヘッドで 43.1%（floodgate の指された手では 36.0%、36.7%。起点以外の 80 マスから無作為に選ぶと 1.25%）。
- **SL から始めた RL でも集中したヘッドが残る**：SL の 10T から始めた RL の 10T で、第 1 T ブロック第 3 ヘッドの偏りは 22.9 から 24.0、第 7 T ブロック第 3 ヘッドは 15.1 から 13.0（11-11）。
- **例の図**：attention/SL_10T/ と attention/SL_R3RRT/（各 50 枚）、attention/藤井羽生_118手目/（SL の 10T 40 枚、SL の R3(RRT) 12 枚）。
- **口頭か補足で言うこと**：例の局面の選び方（重みの大きい順）と一致率。例の手は、SL の 10T で 50 のうち 39、SL の R3(RRT) で 50 のうち 47 が駒を取る手。
- **藤井－羽生戦の 118 手目**：探索なしの policy の 1 位は、SL の 10T も SL の R3(RRT) も ▲5六銀打（水匠5 の読みで 13 手の詰み）。1 手 64 シミュレーションの探索をさせると、どちらも実際に指された ▲4七桂打（5 手の詰み）を指す。図の黒の破線は探索なしの policy の 1 位であることを、図か口頭で伝える必要がある。GUI と図の確かめはパネルで行っている（11-16）。
- 出典：gpw_paper/poster_parts.md の 9 節、mdfolder/attention_map.md の 6c・6d 節、data/floodgate/examples_sl.csv

## 2. 新しい結果の候補：動物将棋（論文のモデル）

- **先生の集計の再現**：無作為な 100,000 局面（4 つの向き）で、6T の第 5 T ブロック第 4 ヘッドは、完全解析で良い手のほうに大きい重みを向ける（最善手と他の手 0.774、順位全体 0.701、重みが最大の手が盤上の最も良い手 44.4%、偶然は 19.3%）。乱数の種 1 の表は、すべての値が先生の値と 0.01 以内。
- **ベースライン**：位置のバイアスだけの重みでは 0.518、学習前の重みでは 0.490。0.774 は盤の中身による。
- **学習の途中**：4,000 ステップで 0.488、12,000 で 0.692、40,000 で 0.774。
- **ヘッドの重みを均等にする**：value の符号が完全解析と合う割合が 85.9% から 83.0% に下がる（ほかの 23 ヘッドでは、下がっても 0.07 ポイント）。policy の 1 位が最善手である割合は 0.4 ポイントしか下がらない。
- **モデルの選んだ手と一致する**：policy が最善手を選ばなかった入力では、他の手より大きい重みが付く割合が、policy の手で 0.75、最善手で 0.65。
- **別の学習**：別に学習した 11 構成でも、6T にだけ良い手のほうに大きい重みを向けるヘッドが現れた（第 4 T ブロック第 1 ヘッド、0.85）。ヘッドの場所は学習ごとに違う。
- **R を含む構成**：9 構成の 92 ヘッドは、無作為な局面ですべて重みがほぼ均等（各マスからの最大の重み × 12 の平均が 1.006〜1.019）。
- 出典：gpw_paper/poster_parts.md の まとめと 1〜7 節、mdfolder/attention_map.md の 6b 節

## 3. 限界として伝える候補

- **IG の全部 0 の基準**：6T の value は全部 0 の入力でほぼ中立だが、駒の IG の符号が手番で変わる（取れる相手のライオンが負になる割合：先手番 2.9%、後手番 87.5%）。同じ基準の厳密な Shapley 値でも起きる（6T で 10.0% と 66.8%）ので、IG だけの性質ではなく、基準の選び方の問題。9×9 の将棋では盤を手番側に回すので起きていない。出典：gpw_paper/IG_基準.md、gpw_paper/poster_parts.md の 8 節。
- **R を含む自己対局のモデルの query と key**：R を含む構成の query と key の重みは、初期値から weight decay の分しか変わっていない（論文の動物将棋の RRTRRT、論文の 9×9 の R3(RRT) の第 2・第 3 T ブロック）。Attention が使われていない状態。原因はわかっていない。出典：mdfolder/attention_map.md の 6d 節。
- **1 つのヘッド、1 回の学習**：動物将棋の主な結果は、6T の 1 回の学習の 1 つのヘッドの結果で、別の学習では別のヘッドに現れる。
