IG：論文の全部 0 の基準では、6T の value がほぼ中立（±0.06）だが、駒の値の符号が手番で変わる（取れる相手のライオンが負になる割合：先手番 2.9%、後手番 87.5%）。同じ基準の厳密な Shapley 値でも、3 つの構成すべてで起きる（6T で 10.0% と 66.8%）ので、IG だけの性質ではない。手番と、同じ局面が現れた回数の平面（以下、手番と回数の平面）を残す基準（駒だけ 0）では、Shapley 値の差は 3 つとも小さくなり、6T の IG では差がほぼ消える（53.8% と 52.8%）。ただし 6R の IG では差が変わらない（2.2% と 25.7%）。その基準は中立でない（6T で、手番側から見て −0.95、−0.85）。手の確率（policy）の IG は、value より方法の間でよく一致する（最大の駒が同じ割合：全部 0 の IG と Shapley 値で 87%、value では 43%）。先後を入れ替えて符号が反対になる駒は 17〜20% で、基準でほとんど変わらない（value の全部 0 の IG では 58%）。

## 1. 無作為な局面での、重みと手の良し悪し（先生の集計の再現）

**文章（ポスター用）**

完全解析から無作為に選んだ 100,000 局面を 4 つの向き（そのまま、左右反転、先後入れ替え、両方）で入力し、相手のライオンを取れる局面とトライ済みの局面を除いた 161,608 入力を用いた。盤上の駒を動かす合法手それぞれについて、動かす駒のマスから行き先のマスへの重みを取り、同じ局面の 2 つの手で、完全解析で良い手（勝ちは早いほど、負けは遅いほど良い）のほうに大きい重みが付く割合を局面ごとに求め、局面で平均した（同じ重みは半分と数える。0.5 が偶然）。
6T の第 5 T ブロックの第 4 ヘッドは、最善手と他の手で 0.77、手の良し悪しの順位全体で 0.70 であった。勝ちの手と引き分けの手で 0.69、引き分けの手と負けの手で 0.67、早く勝つ手と遅く勝つ手で 0.67 であった。重みが最大の手が盤上の最も良い手である割合は 44.4% で、盤上の手を無作為に選んだとき（19.3%）の 2 倍以上である。相手の駒を取る手には大きい重みが付きやすいが（取る手と取らない手で 0.80）、取る手を除いても最善手と他の手で 0.71 であった。
116 ヘッドのうち順位全体で 0.6 を超えたのは 6T の 4 ヘッドだけで、中央値は 0.49 であった。R ブロックを含む 9 構成では、最も高いヘッドでも 0.53 であった。
policy が最善手を選ばなかった入力では、6T の第 5 T ブロックの第 4 ヘッドは最善手より policy が選んだ手に重みを向けた（policy の手と他の手で 0.75、最善手と他の手で 0.65）。同じ尺度で 6T の policy の確率そのものを測ると、順位全体で 0.88 であった。

## 2. 0.77 は何から来るか（6T 第 5 T ブロック第 4 ヘッド、乱数の種 1）

## 5. ヘッドの重みを均等にすると（6T、161,608 入力）

1 つのヘッドの重みを均等（1/12）に置き換え（softmax の出力をフックで置き換える。モデルのコードは変えない）、出力がどう変わるかを見た。

| | policy：最善手と他の手 | policy の 1 位が最善手 | value の符号が完全解析と合う |
|---|---|---|---|
| どのヘッドも変えない | 0.905 | 72.1% | 85.9% |
| 第 5 T ブロック第 4 ヘッドの重みを均等にする | −0.001 | −0.4 ポイント | **−2.9 ポイント** |
| 第 4 T ブロック第 1 ヘッドの重みを均等にする | −0.005 | **−1.0 ポイント** | −0.01 ポイント |
| ほかの 22 ヘッド | −0.0004〜+0.0001 | −0.20〜+0.02 ポイント | −0.07〜+0.13 ポイント |

- RRTRRT は 8 ヘッドのどれの重みを均等にしても、policy の 1 位が最善手である入力の数が 161,608 のうち最大 1 つ変わるだけで、value の符号の一致は変わらない。重みがもともとほぼ均等だから（6 節）。
- 6T のほかの 22 ヘッドの重みを均等にしても、表の 3 つの割合はほとんど変わらない。重みを均等にしたときに下がる割合で見ると、偏った 2 ヘッドのうち、第 5 T ブロックの第 4 ヘッドは value の符号の正しさ（−2.9 ポイント）に、第 4 T ブロックの第 1 ヘッドは policy の 1 位の正しさ（−1.0 ポイント）に効く。
- value の符号は、引き分けでない入力で数えた。

## 6. 重みの偏り（data/dobutsu_all/peaked_*.csv。161,608 入力から無作為に選んだ 2,000 入力で、各マスからの最大の重み × 12 の平均。均等なら 1）

- 順位の尺度は重みの差の大きさを使わない。そのため、ほぼ均等な重みでも小さな差で順位が決まる。R を含む構成のヘッドが最善手と他の手で 0.42〜0.55 と 0.5 からずれるのも、6T の第 2 T ブロックの第 1 ヘッド（1.36）が順位全体で 0.68 になるのも、この範囲のこと。「重みが集まる」こととは別である。

## 11. 想定される質問と答え

- **0.77 は偶然と比べてどのくらいか。** 偶然は 0.5。位置のバイアスだけで 0.52、学習前の重みで 0.49。3 つの標本（乱数の種 1〜3）で 0.768〜0.774。
- **取る手に重みが集まっているだけではないか。** どちらの手も駒を取らない組だけでも 0.71。
- **動かす駒の種類で決まっているだけではないか。** 同じ種類の駒の手どうしでも 0.78〜0.83（取る手を含む）。ライオンは 1 枚なので、ライオンの手どうしの 0.829 は同じ駒の行き先どうしの比較である。
- **このヘッドはモデルの判断に使われているのか。** 重みを均等に置き換えると、value の符号が完全解析と合う割合が 85.9% から 83.0% に下がる。policy の 1 位への影響は 0.4 ポイント。もう 1 つ重みの偏ったヘッド（第 4 T ブロックの第 1 ヘッド）を止めると、value は −0.01 ポイント、policy の 1 位は −1.0 ポイント。ほかの 22 ヘッドの重みを均等にしても、表の割合はほとんど変わらない。
- **重みは正解に沿っているのか、モデルの判断に沿っているのか。** policy が最善手を選ばなかった入力では、他の手より大きい重みが付く割合が、policy の手で 0.75、最善手で 0.65。正解よりモデル自身の判断に沿っている。
- **ヘッドを後から選んだのではないか。** 論文では最善手順の 61 局面でヘッドを選び、選ぶのに使わなかった無作為な局面で確かめた。今回は 116 ヘッドすべてを同じ基準で測り、表の 4 つの尺度（最善手と他の手、取る手を除く、順位全体、重みが最大の手が盤上の最も良い手）では、3 標本ともこのヘッドが最も高かった。負けの局面だけでは、このヘッドは 0.703 で、第 2 T ブロックの第 1 ヘッド（0.704）と同じ程度。駒打ちでは第 6 T ブロックの第 3 ヘッドが最も高いが、その値の大部分は位置のバイアスで説明できる（バイアスだけで 0.63、学習済み 0.68）。
- **R を含む構成ではなぜ重みが均等なのか。** 確かめていない。論文では「R ブロックが近くのマスどうしの形を処理し、T ブロックは盤全体の平均を全マスに配る役割になった可能性」を挙げた。同じ R3(RRT) でも、9×9 の SL のモデルは重みが偏り、self-play のモデルはほぼ均等なので、構成だけでは決まらない。
- **別に学習しても同じか。** 以前に別に学習した 11 構成（18 平面で 100,000 ステップ学習してから 20 平面に広げ、110,000 ステップまで学習したもの。論文の作り方での学習のやり直しではない）でも、6T にだけ手の良し悪しに沿うヘッドが出た（0.85）。場所は違う（第 4 T ブロックの第 1 ヘッド）。
- **向きで変わるか。** 左右反転した入力でも平均は同じ（0.784 と 0.785）。ただし完全解析の局面は左右の一方の向きで保存されていて、「そのまま」も左右の混ざったものなので、局面ごとに同じとは言えない。後手番の入力では 0.02〜0.03 低い（論文のモデルは盤を回さないので、後手番は別の入力になる。低い理由は確かめていない）。
- **複数のブロックをまとめた見方（attention rollout）では。** 0.69 で、第 5 T ブロックの第 4 ヘッド（0.77）より低い（24 ヘッドと並べると 3 番目）。
- **9×9 の「正解」は正しいのか。** 正解ではなく「強いエンジン同士の対局で指された手」。1 つの手しかないので、手の順位全体は数えられない。
- **9×9 の SL のモデルで重みが偏るのはなぜか。** 確かめていない。self-play のモデルとは、学習のデータ（棋譜と自己対局）、量、強さ（SL のモデルが論文のモデルに 100 局で 99〜100 勝）、投了の不具合の有無がすべて違う。
- **IG の基準はなぜ全部 0 なのか。** 盤上の駒も持ち駒もなく、手番と回数の平面も 0 の入力（全部 0）を、「駒がない＝情報がない」自然な基準として選んだ（6 月。引用はない）。後で確かめると、6T の基準での value はほぼ中立（±0.06）で、IG の原論文の勧め（基準での予測がほぼ 0）に合っていた。IG に使ったほかの 2 つの基準は中立にならない（手番側から見て、駒だけ 0 で −0.95 と −0.85、データの平均で −0.89 と +0.89）。
- **後手番の局面で駒の色が反対になるのはなぜか。** 6T では、全部 0 の基準で手番と回数の平面も 0 になることが主な原因と考えられる（仕組みは確かめていない）。同じ基準の厳密な Shapley 値でも起きるので、IG だけの性質ではない。6T では、これらの平面を残す基準ならほとんど起きない（先後を入れ替えて符号が反対になる駒が IG で 58.4% から 7.4%）。ただし 6R の IG では残る（取れる相手のライオンが負になる割合 2.2% と 25.7%）。また、その基準は中立でない。中立と手番によらないことの両方を満たす基準は、今回試した中にない。
- **手の確率の IG は信用できるか。** value より方法の間でよく一致する（全部 0 の IG と全部 0 の Shapley 値で、最大の駒が同じ割合が 87%。value では 43%）。先後を入れ替えたとき符号が反対になる駒は、Shapley 値で 4〜5%、IG で 17〜20%（value の全部 0 の IG では 58%）。
- **IG と Attention の上位のマスは重なるか。** value の IG（全部 0）の絶対値の上位 3 マスと、手番側のライオンからの重みの上位 3 マスの重なりは、第 5-4 が 1.19 で、ヘッドが駒のあるマスから無作為に選んだとき（1.30）より低く、第 4-1 は 1.31 でほぼ同じ。

## 12. 確かめていないこと

- 先生の数字との小さな差：駒打ち（こちら 0.68・14,232 入力、先生 0.69・13,864 入力）、R を含む構成の最高（こちら 0.551〜0.553、先生 0.56）、「重みが最大の手が盤上の最も良い手」の 3 行（3 標本とも先生より少し低い）。11-05 には、これらがこちらの 3 標本の範囲の外にあり（丸めでも説明できない。0.683 は 0.68）、標本の違いか数え方の違いかを区別できなかったので、先生に確かめる案にした。しかし差は小さく（乱数の種 1 では 0.01 以内、3 標本では駒打ちで最大 0.013、最大が最善手で最大 1.3 ポイント）、どちらの理由でも結論は変わらないので、先生には確かめない（2026-11-06 に決めた）。ポスターでは、こちらの数字と先生の数字を 1 つの表に混ぜない。
- 先生の偶然 18.9% の定義は「盤上の最善手の数 ÷ 全合法手の数」と見る（試した 8 つの定義のうち、これだけが 18.9% になる）。
- R を含む構成で重みが均等になる理由。9×9 の SL のモデルで重みが偏る理由。
- 9×9 の test の 115 局（手の 3.4%）は、同じ手順の棋譜が train にもある。SL のモデルの一致率をこれらを除いて数え直してはいない。
