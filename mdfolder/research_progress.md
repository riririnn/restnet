## 1. 目的

Attention Map を用いて、モデルが局面のどこに着目しているか（何を考えているか）を知り、その着目が将棋として妥当かを将棋の言葉で確かめる。
モデルの有用性は強さで示す。動物将棋は田中先生の完全解析との一致率、9×9 の将棋は対局の強さ。

**使うゲームの役割：** ResTNet の論文の構成に対応させた（2026-09 の方針）。9×9 囲碁の構成の比較 → 動物将棋（完全解析があり、一致率で測れる。将棋からは遠く、外部の相手がいない）と 5五将棋（将棋の規則をほぼ備え、外部エンジンと対局できる。完全解析はない）。19×19 囲碁の Attention の可視化 → 9×9 の将棋。

## 4. 主な結果と、証拠の強さ

| 結果 | 数字 | 注意 |
|---|---|---|
| 動物将棋の一致率（論文の 11 構成、全 239,784,182 局面） | 0.82〜0.87。6T が最高（0.865） | 探索なしの policy で数えた値。Elo とはほぼ相関しない（順位相関 0.11） |
| 総当たりの Elo（論文の 11 構成） | 6T が最低、5R1T が最高 | 1 組 100 局。6T は後手の引き分けが多い。論文からは外した |
| 6T の Attention が手の良し悪しに沿う（先生の集計） | 第 5 T ブロック第 4 ヘッド 0.774 | 別の学習では違うヘッド（第 4 T ブロック第 1 ヘッド 0.853）。6T だけに現れる点は 2 つの学習で共通 |
| R を含む構成の Attention はほぼ均等 | 92 ヘッドで偏り 1.006〜1.019 | Attention が使われていない状態。query と key の重みは weight decay だけの大きさのままで、v2 の棋譜では勾配が weight decay に負けている（attention_map.md 6d）。R があると勾配が小さくなる理由は未解決 |
| IG の全部 0 の基準 | 取れる相手のライオンの符号が手番で変わる（2.5% と 84.3%） | 厳密な Shapley 値でも起きる。基準の選び方の問題 |
| 9×9 の R3(RRT)（論文） | AobaZero の初期の重みに 60.8%、31.5%。重みはほぼ均等 | **投了の不具合のある学習。** 局面は 1 局の 3 局面 |
| 9×9 の SL | test の 1 位の一致 0.474〜0.504。論文の自己対局のモデルに 40 勝 0 敗 | 不具合なし。R3(RRT) の SL の重みは偏っている（10.2）。論文の「ほぼ均等」と違う |

## 6. 未解決の問い

1. 一致率は強さを測っているか（Elo とほぼ相関しない）。
2. 6T のヘッドは安定した発見か（学習ごとに場所が違う）。v2 の先生の集計で 3 つ目の例が得られる。
3. R を含む構成で Attention が均等になるのはなぜか。
4. 論文の 9×9 の結論は、正しく学習したモデルでも成り立つか。
5. 9×9 の SL のモデルで重みが偏るのはなぜか（データ、学習の量、不具合の有無が同時に違う）。
6. IG の基準をどう選ぶか。
