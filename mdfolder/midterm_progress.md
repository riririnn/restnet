聞き手は学科・専攻の審査（専門外の先生を含む）。GPW 2026 の論文（gpw_paper/paper.tex）の結果と、今後の計画を話す。

## 1. ひとことで

AlphaZero 型の将棋 AI（ResTNet）が「盤のどこに着目して考えているか」を Attention Map で可視化し、
その着目している所が将棋として妥当かを、正解のわかるゲーム（動物将棋）で確かめた。

## 2. 背景（専門外の先生向けに、論文より丁寧に）

- **AlphaZero**：人間の棋譜を使わず、自分どうしの対局（自己対戦）だけで強くなる手法。ネットワークは、
  各手の確率（policy）と、局面の勝ちやすさ（value）を出す。強いが、なぜその手を選んだかは人間に読めない。
- **ResTNet**（IJCAI 2025）：AlphaZero のネットワークに Transformer を混ぜたもの。
  - R ブロック＝近くのマスの形を処理する畳み込み。T ブロック＝盤全体のマスどうしの関係を処理する Transformer。
  - T ブロックには「あるマス（起点）が、ほかのどのマスの情報をどれだけ使うか」という重み（attention）があり、
    それを盤の形に並べた図が **Attention Map**。
  - 原論文は、囲碁・Hex の図で死活やシチョウを捉えると示したが、図を数枚見ただけで、多くの局面で数えてはいない。
- **なぜ将棋か**：持ち駒・成り・駒ごとに違う動きがあり、選べる手の数も多い（9×9 の将棋で 11,259）。
  特徴量や選択肢の多い実世界のモデルへの応用の可能性を示す検証の対象になる。将棋系に ResTNet を使った例はない。
- **なぜ動物将棋か**：3×4 の盤の小さい将棋で、全局面の勝敗と最善手がわかっている（完全解析、78 手で後手勝ち）。
  だから「AI が重みを向けているマスが正解か」を、選んだ例でなく無作為な多くの局面で数えられる。
- **IG（Integrated Gradients）**：盤上の駒や持ち駒が、出力（手の確率や value）をどれだけ押し上げ・押し下げたかを
  求める手法。Attention Map（内部の重み）とは別の見方として使った。

## 3. 目的（論文 1 章）

Attention Map を使って、モデルが局面のどこに着目しているか（何を考えているか）を知る。
「正解に関わるマス（取れる相手のライオン、最善手の行き先など）に、選んだ例だけでなく無作為な局面でも重みが向く」ことを、
妥当な着目とみなす。9×9 の将棋は正解がないので、実際に指された手を仮の正解として見るにとどめる。

## 4. やったこと

| | 動物将棋 | 9×9 の将棋 |

## 5. 結果（話す順）

### 5.1 モデルの精度と強さ（4.1 節）
- 動物将棋：探索なしの policy の 1 手が最善手と同じ評価になる割合は、11 構成とも 0.82〜0.87
  （完全解析の 239,784,182 局面）。6T が最も高く 0.865。
- 9×9 の将棋：AobaZero の学習初期の重みに対して、w50 に 60.8%、w60 に 31.5%（各 400 局）。
  → 強さは AobaZero の学習初期の重みと同じ程度。

### 5.2 動物将棋：Attention Map（4.2 節）— 一番の結果
- 最善手順の 61 局面でヘッドを選ぶと、全 116 ヘッドのうち均等を明確に上回ったのは
  **6T の第 5 T ブロックの第 4 ヘッドだけ**（1.99。ほかの R を含む構成の 92 ヘッドは 0.994〜1.006）。
- 選ぶのに使わなかった**無作為な局面**（19,434 局面）で、手番側のライオンを起点に数えると、このヘッドの重みが最大のマスは
  - 相手のライオンを取れる局面の **90.1%** で相手のライオン
  - 最善手がライオンの手の局面の **87.7%** でその行き先
  - ライオンに王手をかけている駒がある局面の 65.2% でその駒、粘る手の 51.0% でその行き先
  - 最初の 3 つは、6T のほかの 23 ヘッドの最高より、95% 信頼区間が重ならずに高い。
- R を含む構成は、重みがほぼ均等（最善手順の 61 局面で、動かす駒のマスからの重み × 12 は、どのヘッドも 1.04 未満（最大 1.031）。
  無作為な局面では RRTRRT を数え、中央値 1.01）。
- 例：6T が勝ちを失った局面でも、このヘッドは取れる相手のライオンに重みを集めていた（6.69）が、policy は別の手を選んだ。
  → 「重みを向けているマス」と「選んだ手の理由」は別、という注意点として話す。

### 5.3 9×9 の将棋（4.3 節）
- 藤井－羽生戦（第 11 回朝日杯 準決勝）の 3 局面で、重みは均等の 1.03 倍以内とほぼ均等。
- 図ごとに [0, 1] に正規化すると濃淡が出るが、実際の手の行き先や相手の玉は濃いマスに入らない。
  → 正規化した図だけを見ると、何かに着目しているように見えてしまう、という注意点。
- 手の確率を押し上げた駒（持ち駒の桂など）は、Attention Map ではなく IG で読み取れた。

### 5.4 持ち駒（4.4 節）
- Attention Map には持ち駒の場所がないので、1 枚を相手に渡したときの重みの変化と、持ち駒の IG で見た。
- 動物将棋（6T の第 4 T ブロックの第 1 ヘッド）は、きりんの有無で重みを向けるマスが変わった。
- 9×9 の将棋は、全ヘッドで変化が 0.001 以下（ほぼ表れない）。図の局面では、どちらのゲームも打つ駒が手の確率を最も押し上げた（全部 0 の基準の IG で）。

## 6. 論文に書いた限界（質問されたら正直に）

- 例の図は説明しやすい局面を選んだもの。無作為な局面で確かめたのは、動物将棋の手番側のライオンを起点とした重みだけ。
- 9×9 の将棋は 1 局の 3 局面だけで、モデルも強くない。
- IG の値は基準（全部 0 の入力）の選び方で変わる。
- 提出後にわかったこと（自分から伝える）：
  - 動物将棋の value の IG では、全部 0 の基準だと、駒の符号が手番で反対になることがある。
    同じ局面を先手番・後手番の 2 つの向きで入れると、6 割のマスで符号が反対（取れる局面で相手のライオンが青になるのは、先手番 5%、後手番 85%）。
    手番の平面も 0 から一緒に増えるため。駒だけ 0 の基準では 1 割に減るが、その基準では value が中立にならない（手番側から見て −0.9 前後）。
  - 動物将棋の policy の IG では、この基準による反転は起きていない（向きで符号が違うマスは 2 割ほどあるが、どちらの基準でも同じで、モデルの手の確率が向きで違うため）。
  - 9×9 の将棋は盤を手番側に回して入れるので、value でも policy でも起きていない。
  - Attention Map の結果と、精度・強さ（4.1 節）は、IG を使っていないので影響しない。

| 3 構成の学習率 | そろえる（0.02 → 70,000・90,000 ステップで半分 → 1000 iteration まで 0.005） | 構成の違いだけを比べるため |
| IG と Attention の重なり | 提出後に回した | 「駒のあるマスに重みを向けているだけ」を超えるかを、基準を比べて（全部 0、駒だけ 0、動物将棋は Shapley 値も）、信頼区間つきで |
| 9×9 の将棋の局面を増やす | 未着手 | 強いエンジンの最善手を仮の正解にして、多くの局面で数える |

## 8. 想定される質問と答え（下書き）

- **Q. Attention Map は判断の説明になるのか？**
  A. それ自体を説明とはみなしていない。重みが向く場所を、正解と照らし合わせて妥当かを確かめた。
  動物将棋では、正解のマスに無作為な局面でも重みが向くヘッドがあったが、policy が別の手を選ぶ局面もある。
- **Q. なぜ 6T だけ偏ったヘッドが出たのか？**
  A. まだわからない。R を含む構成では、R ブロックが近くの形を処理し、T ブロックは盤全体の平均を配る役割になった
  可能性がある（論文 4.3 節）。10T と、学習を延ばした 10R・R3(RRT) で確かめる（計画 7 章）。
- **Q. 1 回の学習の結果ではないか？**
  A. そのとおり。論文の主張は学習したモデルについてのもので、構成一般の性質とは言っていない。
- **Q. 9×9 の将棋は何がわかったのか？**
  A. 重みはほぼ均等で、正規化した図の濃淡は判断の根拠とは言えない。手の理由は IG のほうが読み取れた。
  モデルを変えて調べ直す余地がある。
- **Q. 図 2 で、取れるはずの相手のライオン（a3）が青（value を押し下げた）なのはなぜか？**
  A. 大きさ（盤上で 2 番目）は、基準を変えても同じなので、重みが集まった a3 は value の計算に大きく関わっていると言える。
  ただし符号（青）には意味を読み取れない。取れる局面を数えると、相手のライオンの色は手番と基準の選び方でほぼ決まっていた
  （全部 0 の基準で、青は先手番 5%、後手番 85%）。前のミーティングでの「相手のライオンがいること自体が value を下げる」という説明は、データで成り立たなかった。
- **Q. なぜ全部 0 を基準にしたのか？**
  A. IG の原論文は、基準での予測がほぼ 0（中立）になるものを選び、確かめることを勧めている。全部 0 の入力での value は、
  動物将棋で +0.06、9×9 の将棋で +0.04 でほぼ 0。駒だけ 0 にして手番を残す基準は、動物将棋で value が −0.9 前後になり中立でない。
  どちらにも弱点があり、提出後は基準を比べている（動物将棋は駒が 8 枚なので、駒を足す順番をすべて平均する Shapley 値も厳密に計算できる）。
