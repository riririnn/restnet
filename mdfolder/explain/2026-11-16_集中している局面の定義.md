# 「集中している局面」の定義：文献の調査（2026-11-16）

問い：同じヘッドの中で、Attention が「集中している局面」と「集中していない局面」を分ける定義は、Attention Map を使った論文でどう決められているか。

読み方：3 つの分野（NLP のヘッドの分析、画像の Transformer、ゲームのモデル）の論文 18 本を、arXiv の PDF の本文で読んだ。引用はすべて本文から。下の表の主な引用は、私が本文の文字列で確かめた（Voita、Clark、Vig 2020、Gu、DINO、Jenner、Mott、ResTNet）。会議名のうち、PDF の頭書きで確かめていないものは「未確認」と書いた。

## 結論

- **同じヘッドの中の局面を、集中の値の閾値で分ける定義をした論文は見つからなかった。**
- 集中の尺度は 2 種類ある。
  - ヘッドの平均：Voita の confidence（最大の重みの平均）、Clark のエントロピーの平均、ViT と Raghu の attention distance。どれもヘッドを比べる値。
  - 1 つの query の値：Vig & Belinkov のエントロピー、Zhai の行のエントロピー。定義はしているが、局面を分けるのには使っていない。
- 閾値がある論文は 4 本で、値の理由がはっきりしているのは 2 本（Vig 2020 の null model、Mott のアブレーション）。Gu 2024 は「最適な閾値を決める原理的な方法はない」と書いている。

## この PC のデータで確かめたこと（data/floodgate/hand_sl_*.npz、駒打ちの局面）

決まった値の閾値は、同じヘッドの中の局面よりも、ヘッドを分ける。

| ヘッド | 最大の重み × 81 の 4 分の 1 点 | 10 を超える局面 | 24.3（Vig 2020 の 0.3）を超える局面 |
|---|---|---|---|
| SL の 10T 第7Tブロック第3ヘッド | 14.5／20.0／26.8 | 92.4% | 33.3% |
| SL の 10T 第9Tブロック第3ヘッド | 3.7／4.8／6.4 | 4.4% | 0.0% |
| SL の 10T 第1Tブロック第3ヘッド | 26.4／28.0／29.0 | 93.8% | 84.0% |
| SL の R3(RRT) 第2Tブロック第2ヘッド | 6.5／9.1／13.8 | 43.4% | 5.5% |

SL の 10T の第1Tブロック第3ヘッドは、最大の重み × 81 がほとんどの局面で 26〜29 である。最大がいつも同じマスに向くヘッドかどうかは、確かめていない。Voita は文末の記号、Vig & Belinkov は最初のトークンを除いており、同じ考え方の除外が要るかもしれない。

## 候補

1. **局面を 2 つに分けず、続いた値のまま使う。** query ごとの最大の重み × 81（Voita の confidence の query ごとの版）と、変化などとの順位相関・4 分の 1 ずつの比較を報告する。文献の使い方に最も近い。
2. **「集中している」はヘッドの判定のままにする（線 1.077）。** 線は、ほぼ均等なモデルの最大で、Vig 2020 の null model の確かめ、Clark の均等の線と同じ考え方。同じヘッドの中の局面は、1 のように続いた値で扱う。
3. **決まった値の閾値（Vig 2020 の 0.3 など）で局面を分ける。** 文献の裏付けはあるが、上の表のとおりヘッドで割合が 0〜84% と違い、ヘッドの違いが混ざる。Gu 2024 のとおり値に原理はないので、いくつかの値で結果が変わらないかを示す必要がある。
4. **ヘッドごとの分位点（4 分の 1 など）で分ける。** 11-16 の持ち駒の測定で使った方法。文献には見つからなかったので、使うなら自分たちの選択として書く。
