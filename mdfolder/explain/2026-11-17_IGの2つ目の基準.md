# IG の 2 つ目の基準：駒と持ち駒を 0（2026-11-17）

本人の依頼（11-16 23 時）：「データの平均と駒だけ０についてふさわしいほうどちらかを利用してください」。計画（/home/rin/.claude/plans/generic-tickling-axolotl.md）で、Claude が「駒と持ち駒を 0」を選び、理由とともに本人が承認した。この文書は、その理由と弱い所を、確かめた出典とともにまとめたもの。本人が読んで理解してから、資料に使う。

## 基準の定義

- **全部 0**：入力のすべての平面を 0 にした入力（論文の基準）。
- **駒と持ち駒を 0**：盤上の駒の平面と持ち駒の平面だけを 0 にし、同じ局面の回数・手番・手数の平面は局面のままにした入力。
  - 動物将棋 v2：平面 0〜9（駒）と 12〜17（持ち駒）を 0。平面 10・11（同じ局面の回数）と 18（先手番なら 1）は残す（xai_analysis.py の DOBUTSU_PIECE_PLANES）。
  - 9×9：8 局面すべての駒（各局面の平面 0〜27）と持ち駒（31〜44）を 0。回数（28〜30）、手番（360）、手数（361）は残す（xai_analysis.py:351 の SHOGI_PIECE_PLANES）。
- **データの平均**：多くの局面の入力の平均（Czech らの図 5 の基準）。9×9 では 2,560 局面の入力の平均。

## この基準を選んだ理由

1. **問いに合う。** 研究の目的は、モデルが盤上の駒と持ち駒のどれを使って評価しているかを知ることである。IG は、入力と基準の差を特徴に分ける。この基準では、駒と持ち駒だけが入力と基準で違うので、IG の合計は「局面での value − 同じ手番・同じ回数で駒のない盤での value」になり、その全部が駒と持ち駒に割り振られる。
   - 全部 0 の基準では、平面 10（このデータで常に 1）と、先手番の入力の平面 18 が、入力と基準で違う。後手番の入力の平面 18 は、基準と同じ 0 である。そのため、手番の平面の IG は先手番の入力にだけ付く。
   - 11-16 の v2 の 6T の 4,000 入力では、全部 0 の基準で、回数と手番の平面（10・11・18）の IG の平均は、終わっていない局面の入力で −0.109（先手番 −0.160、後手番 −0.059）、相手のライオンを取れる局面の入力で +0.009 だった。回数と手番の平面の IG は、|IG| の合計の 5.9% を占めた。駒と持ち駒を 0 の基準では 0.0% だった（data/dobutsu_all_v2/old_1116/ig_v2_6T.txt の「share of the total |number|」と ig_v2_6T.npy。11-17 に計算し直した）。
   - 11-17 の v2 の IG では、全部 0 の基準で平面 10 だけに付いた IG の平均は、終わっていない局面の入力で 6T −0.037、RRTRRT −0.308、6R −0.225 だった（data/dobutsu_all_v2/ig_planes_v2_<構成>.txt の repetition 1st の行）。11-17 の 6T は 1,000 局面で、上の行の 11-16 の 500 局面とは別の局面である。上の行は平面 10・11・18 の合計で、この行は平面 10 だけである。
   - データの平均の基準では、空いているマスも入力（0）と基準（平均）で違う。そのため、「駒がないこと」にも IG が付く。
2. **文献の「基準は不在を表す」という条件に合う**（原文で確かめた）。
   - Sundararajan, Taly, Yan（ICML 2017、arXiv 1703.01365）5 節："So we would additionally like the baseline to convey a complete absence of signal, so that the features that are apparent from the attributions are properties only of the input, and not of the baseline."
   - 同じ論文の 6.4 節（翻訳）："For baseline, we zero out the embeddings of all tokens except the start and end markers." 開始と終了の記号を残して、ほかのトークンの埋め込みを 0 にした。
   - 同じ論文の 6.5 節（化学）："The baseline input is obtained zeroing out the feature vectors for atom and atom-pairs." 原子と原子対の特徴ベクトルを 0 にした。残すものは書かれていない。
   - Sundararajan と Najmi（ICML 2020、arXiv 1908.08474）4.3 節の Remark 4.7（IG ではなく Baseline Shapley について）："We can use the baseline to model the explanation context." "Such an explanation is achievable by selecting a baseline that coincides with the explicand on immutable features." 同じ Remark の次の文："However, this does pose an additional cognitive load to select the baseline and interpret the dependence of the explanation on the baseline."
3. **ゲームの説明の研究でも、駒を取り除くことを「不在」として使っている**（原文で確かめた）。
   - Puri ら（SARFA、ICLR 2020）2 節："in chess, we can perturb the board position by removing the piece in the f th square."
   - Zhou ら（arXiv 2310.09838、囲碁）3.1 節：石を取り除いた局面を使う。ただし、取り除くのは選んだ 10 個の石だけである（3.2 節）。
   - Spinnato（2025、arXiv 2510.25775、チェスの SHAP。原文には CEUR-WS Proceedings に掲載予定と書かれている。会議名は確かめていない）3 節：駒を取り除き、両方のキングと手番などのメタデータを残す。ただし、取り除いたあとに不正な局面になるときは、手番を入れ替えることがある。
   - 廣瀬・和賀・末永（日本ソフトウェア科学会 2023、将棋）4.1 節：「盤上の駒や持ち駒を局面から 1 つ取り除く」などの操作で局面を変える。
   - どれも摂動か SHAP で、IG の基準としてこの形を使った先行研究は見つけていない。
4. **同じ不在の定義の厳密な Shapley 値と比べられる。** 動物将棋では、同じ「駒を取り除く」という不在の定義で、厳密な Shapley 値を計算できる（scripts/ig_statistics.py の shap_removed）。厳密な Shapley 値は、IG とは別の公理で決まる別の方法で、IG の正解ではない（Sundararajan ら 2017 の Remark 5："it seems somewhat subjective to prefer one result over the other"）。同じ基準どうしの IG と厳密な Shapley 値の順位相関は、駒と持ち駒を 0、全部 0 の順に、6T で 0.82 と 0.84、RRTRRT で 0.84 と 0.80、6R で 0.80 と 0.76 だった（11-16、4,000 入力、data/dobutsu_all_v2/old_1116/ig_v2_*.txt）。差は 0.04 以下で、向きは構成で違う。この比べ方は、基準を選ぶ理由にはならない。
5. **2 つのゲームで、0 にする平面の種類が同じである。** どちらのゲームでも、0 にするのは盤上の駒と持ち駒の平面で、残すのは回数と手番（9×9 では手数も）の平面である。違う点：動物将棋 v2 の入力は 1 局面、9×9 の入力は 8 局面で、9×9 では前の 7 局面の駒の平面も 0 にするので、前の 7 局面の駒の平面にも IG が付く（SL の 10T で、1 つ前の局面の自分の駒の平面の合計が +0.870、data/floodgate/ig_planes_SL_10T.txt）。基準での value は、動物将棋 v2 で約 −1、9×9 で −0.777〜+0.728 である。

## 弱い所

- Czech ら（arXiv 2304.14918 4.3 節）は、平面ごとの平均に "the mean of all validation input features" を基準として使った。1 局面の図（図 8 と付録）は全部 0 の基準である。駒と持ち駒を 0 は、Czech らと違う選択なので、理由とともに書く必要がある。なお、Czech らは図 5 の平均をどの局面で取ったかを書いていない。
- 9×9 では、駒と持ち駒を 0 の基準のほうが、全部 0 の基準より中立から遠い。7 つのモデルで、全部 0 の基準での value は −0.099〜+0.171、駒と持ち駒を 0 では −0.777〜+0.728 だった。
- 9×9 では、駒と持ち駒を 0 の基準での value が局面ごとに違う（標準偏差は SL の 10T で 0.130、SL の R3(RRT) で 0.108、7 つのモデルで 0.026〜0.183）。残した平面（回数、手番、手数）のどれが原因かは確かめていない。
- 上の理由 4 のとおり、厳密な Shapley 値との順位相関では、駒と持ち駒を 0 が全部 0 より良いとは言えない。
