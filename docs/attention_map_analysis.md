# Attention Map 均等分散問題の分析

## 1. 観察された問題

すべてのレイヤー・ヘッドの組み合わせ（L1/L2 × H1〜H4 = 8通り）で
Attention Map の集中度が **0.0%〜0.1%** となり、盤面全体が均等に赤く表示される。

```
Layer 1:
  Head 1: min=0.00992  max=0.01552  集中度=0.056%
  Head 2: min=0.01035  max=0.01520  集中度=0.019%
  Head 3: min=0.00957  max=0.01525  集中度=0.024%
  Head 4: min=0.00931  max=0.01478  集中度=0.018%

Layer 2:
  Head 1: min=0.00984  max=0.01727  集中度=0.024%
  Head 2: min=0.00935  max=0.01682  集中度=0.064%
  Head 3: min=0.01014  max=0.01533  集中度=0.034%
  Head 4: min=0.00949  max=0.01631  集中度=0.072%

均等値（理論値）: 1/81 = 0.01235
```

最大値でも均等値の **1.4倍未満**。ほぼ完全な均等分散。

---

## 2. Attention Map とは何か

Transformer の Self-Attention では、各マス `i` が他のマス `j` に
どれだけ「注目」して自分の表現を作るかを計算する。

```
Q = W_q · x        # Query: 「何を探しているか」
K = W_k · x        # Key:   「何を持っているか」
V = W_v · x        # Value: 「実際に渡す情報」

attention_logit[i,j] = (Q[i] · K[j]) * scaling
attention_weight[i,j] = softmax_j(attention_logit[i,:])
output[i] = Σ_j attention_weight[i,j] * V[j]
```

`attention_weight[i,j]` が今回可視化しているもの。

**重要**: これは「どの手を指すか」とは直接関係しない。
あくまで「マス i の表現を作るためにマス j をどれだけ参照したか」。

---

## 3. 均等分散の直接原因

### 3-1. Softmax への入力（logit）が小さすぎる

実測値：
```
Q·K dot products: min=-0.230, max=0.293, std=0.071
scaling factor:   0.125  (= 1/sqrt(d_head))
→ logit 範囲: 約 ±0.3
```

softmax に入力される値が全マスで ±0.3 程度しか違わない場合：

```
softmax([0.3, 0.0, -0.3, ...]) ≈ [0.015, 0.012, 0.010, ...]  ← ほぼ均等
softmax([3.0, 0.0, -3.0, ...]) ≈ [0.95,  0.05,  0.001, ...]  ← 集中
```

logit の分散が小さいほど softmax 出力は均等に近づく。
今のモデルでは logit std ≈ 0.07 × 0.125 ≈ 0.009 なので、
softmax 後は **理論均等値 0.012 からほとんどずれない**。

### 3-2. Relative Position Bias が未学習

`MSA_rel` には学習可能な位置バイアスがある：

```python
self.relative_bias_table = nn.Parameter(
    torch.zeros((2H-1)*(2W-1), num_heads)  # 初期値 = 0
)
```

実測値：
```
Layer 1 relative_bias_table: std = 0.0001  ← ほぼ 0
Layer 2 relative_bias_table: std = 0.00003 ← さらに小さい
```

これが学習されると「隣接マスに注目しやすい」「遠距離を無視する」
といった空間的パターンが生まれるはずだが、**ほぼゼロのまま**。

### 3-3. Q・K 射影の重みスケールが小さい

```
projq weight mean absolute value: 0.0153
projk weight mean absolute value: 0.0153
```

これらが小さいと Q・K の内積も必然的に小さくなり、
softmax への入力 logit が小さくなる。

---

## 4. なぜこうなったか（考えられる原因 4 つ）

### 原因 A：訓練ステップが不足している

現在使用モデルは `weight_iter_2200.pt`。
AlphaZero 方式の自己対局学習では、**初期は方策・価値の学習が優先**される。
Transformer の Q・K 射影や Relative bias は勾配が小さく、
学習初期には更新されにくい。

```
訓練初期の損失勾配の流れ:
  L_total = L_policy + L_value
  ∂L/∂W_q, ∂L/∂W_k が小さい → Q,K がほぼ変化しない → 均等分散が続く
```

**検証方法**: より進んだイテレーションのモデル（例: iter_10000）と比較する。

---

### 原因 B：Residual 接続がアテンションをバイパスさせている

アーキテクチャ: `R → R → T → R → R → T`

T-block の内部は以下の構造：

```
output = x + MSA(LayerNorm(x))  ← 残差接続
       = x + Σ_j attention[i,j] * V[j]
```

アテンションが均等（≈ mean(V)）であっても **残差 x が支配的**なため、
ネットワーク全体の出力は問題なく計算できる。
つまり「アテンションが何もしなくてもネットワークは機能する」ため、
アテンションが均等のままでも損失が下がり、**学習の圧力がかからない**。

これは "Lazy Attention" とも呼ばれる現象で、
残差接続のある Transformer では頻繁に観測される。

---

### 原因 C：将棋タスクに空間的集中アテンションが不要かもしれない

テキスト処理と将棋の違い：

| | テキスト | 将棋盤面 |
|---|---|---|
| トークンの多様性 | 語彙が膨大（多様） | 82種程度（少ない） |
| 空きトークン | ほぼない | 大半（平均50マス以上が空） |
| 位置情報 | 相対位置が重要 | Conv で既に学習済み |

将棋盤面では Conv（R-block）が局所パターンをすでに捉えているため、
T-block は「全体の大局観を均等に集約する」だけで十分な可能性がある。
この場合、均等分散は**バグではなく設計通りの動作**。

---

### 原因 D：Softmax の温度（Temperature）が高い

現在の scaling factor は `1/sqrt(d_head) = 0.125`。
これは標準的な値だが、`d_head` が大きいほど logit が小さくなり均等化する。

```python
self.scaling = (self.emb_size / self.num_heads) ** -0.5
# emb_size=256, num_heads=4 → d_head=64 → scaling=0.125
```

scaling を小さくする（= 温度を下げる）と softmax がより尖る。
ただし訓練済みモデルの scaling を変えると出力が変わるため、
**事後的には変更できない**。

---

## 5. 解決方法

### 解決策 1：より多く訓練されたモデルを使う（即効・推奨）

```bash
# 利用可能なモデルを確認
ls shogi_9x9_gaz_2R1T2R1T_P_TV_n50/model/
# → weight_iter_200.pt, 400, 600, 1200, 2000, 2200

# より進んだイテレーションがあれば試す
# iter が進むほど Relative bias と Q,K 重みが洗練される可能性
```

**期待効果**: 高い。訓練が十分であれば自然に集中したアテンションが現れる。

---

### 解決策 2：Pre-softmax logit を可視化する（即効・実装済み対応可能）

softmax 前の `Q·K` 内積値をそのまま可視化する。

```python
# 現在: softmax後 → 均等化されている
attn = softmax(Q[i] · K.T * scaling)   # 0.009〜0.017

# 代替: softmax前 → 差が大きい
logit = Q[i] · K.T * scaling           # -0.230〜+0.293
```

softmax 前は値の範囲が約 **0.5** あり、softmax 後（約 **0.008**）の
60倍以上の情報量を持つ。これを可視化するだけで論文に近い図が得られる可能性がある。

**実装**: `block.MSA.attn()` を改造して softmax 前の `dots` も返すように変更。

---

### 解決策 3：アーキテクチャ再訓練時に Relative bias の初期値を変える（長期）

```python
# 現在: ゼロ初期化 → 学習されにくい
self.relative_bias_table = nn.Parameter(torch.zeros(...))

# 改善案: 正規分布で初期化 → 初期から位置依存性を持つ
self.relative_bias_table = nn.Parameter(
    torch.randn(...) * 0.02  # 標準偏差 0.02
)
```

**期待効果**: 高い。ただし**再訓練が必要**。

---

### 解決策 4：アテンション Entropy 正則化を加える（長期）

訓練時の損失に「アテンションのエントロピーを下げる」正則化項を加える。

```python
# 追加損失: エントロピーを最小化 → 集中したアテンションを促す
attn_entropy = -torch.sum(attn * torch.log(attn + 1e-12), dim=-1).mean()
loss = loss_policy + loss_value + λ * attn_entropy   # λ = 0.01 など
```

**期待効果**: 中程度。過度に使うと方策・価値の学習を妨げる可能性がある。

---

### 解決策 5：T-block の数を増やす（長期）

現在: `R→R→T→R→R→T`（T-block 2個）

```
提案: T→R→T→R→T→R→T  または  R→T→T→T→R→T
```

T-block が多いほど各ヘッドが異なる役割（局所・大局・攻め・守り）を
分担して学習できる。

**期待効果**: 高い。ただし**アーキテクチャ変更 + 再訓練が必要**。

---

## 6. Attention Map の理論的解釈

### なぜ論文（IJCAI-25）では集中した Attention Map が見えたか

論文では：
1. 複雑な中盤局面を手動選択
2. 複数のヘッドを試して最も特徴的なものを Figure に掲載
3. 論文モデルは訓練がより進んでいる可能性
4. **異なる Scaling / アーキテクチャパラメータの可能性**

### 均等分散が意味すること

均等分散の Attention = **Global Average Pooling として機能している**

```
output[i] = Σ_j (1/81) * V[j]  ≈ mean(V)
```

つまり T-block は「全マスの情報を均等に混ぜる」操作をしており、
空間的な局所集中は Conv（R-block）が担当している可能性が高い。

## 8. 終盤局面での実測結果（追記）

### 局面：後手玉が右上に追い詰められた終盤

```
SFEN: k8/1p7/KP7/9/9/9/9/9/9 b RBGSLNrb2g2s2l2n3p 1
手: R*9b（飛車を9二に打つ）
クエリ位置: 9b (row=1, col=0)
```

### 全ヘッド比較で分かったこと

均等値（1/81）を基準にした正規化（修正後）で可視化すると、
各ヘッドがまったく**異なる空間パターン**を示した：

| ヘッド | 最も注目している領域 | 解釈 |
|--------|---------------------|------|
| L1H1 | 9筋・中央左 | 玉の縦ライン |
| L1H2 | 1筋（右上） | 盤面右側の状況 |
| L1H3 | 右上隅 | 右隅方向 |
| L1H4 | 左下 | 9筋外の遠隔マス |
| **L2H1** | **9筋（玉のいる列）** | **玉の位置を強く意識** |
| L2H2 | 左中段 | c-d段の左側 |
| L2H3 | 中央右 | 盤面中央右 |
| L2H4 | 1筋（右端） | 右端ライン |

**L2H1 では後手玉がいる 9a（隣接マス）への注目が最大**になっており、
モデルが「玉の位置」を認識していることが示唆される。

### 修正前との比較

| 正規化方法 | 結果 |
|-----------|------|
| min-max（修正前） | 全タイルが赤→ノイズを誇張、パターン不明瞭 |
| 均等値基準（修正後） | 白〜薄赤が基準、集中部分のみ赤→パターンが読める |

### 結論

**「完全な均等分散」という判断は min-max 正規化による誇張が原因だった。**
均等値を基準にした正規化では、ヘッドごとに異なる空間パターンが存在し、
特定のヘッド（L2H1）は玉の位置への注目を示す。

絶対値は小さい（均等値の約 1.4 倍）ため、論文ほど鮮明ではないが、
これはモデルの訓練量（iter_2200）の限界と考えられる。
